# Magic 8 Button

Tap the big red button for Yes, No, or Maybe. Yes bursts gold stars, No puffs gray smoke, Maybe pops question marks. Flat-shaded, works on phones, no install.

## Edit the smoke
1. Edit `smoke.png` (512×512, transparent background) in any paint program; save as PNG with the same name.
2. Run `python3 embed_smoke.py` in this folder to bake it into `index.html`, so the single HTML file works on its own.
